01 / THE EXECUTION CONTRACT

Decide the boundaries.
Not every next step.

No surprise tool permissions halfway through a run. No pretending that scheduled work is guaranteed success.

01

Just type spawn.

The terminal wizard asks for your goal, documents, completion criteria, models, and limits. No TOML edits.

goal + criteria + sources
02

See the tradeoffs.

Compare profile-based cost/time scenarios and planned coverage. Pin a model or let the heuristic scheduler choose.

preview → adjust → approve
03

Keep the useful work.

Tighten limits between calls. Spawn replans unfinished criteria and saves a cited report, trace, and receipt.

complete what fits / defer the rest

PERMISSION FIRST. AUTOMATION AFTER.

Less babysitting.
Same boundaries.

The MVP reads approved local text files and sends excerpts only to approved models. It does not browse the web, run a shell, or give an agent arbitrary tools.
